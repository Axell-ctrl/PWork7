Практическая работа №7                                            
Задание: Определить кол-во участников, далее вывести таблицу с участниками и их баллами.                             
Итоговая таблица: Сумма всех баллов 3 школ, лучшая школа, лучший участник (кол-во баллов).

Программа начинает работу с настройки интерфейса: очищает экран, меняет цвет фона на темно-синий, цвет текста — на белый, а также задает программное имя в заголовке консоли.
Далее происходит присвоение integer переменными students, score1, score2, score3, последние 3 переменные инициализируются со значением 0.
Консоль приветствует пользователя и просит его ввести значение участников. Далее происходит инициализация переменных (в integer), которые будут использованы в цикле:
MaxStudentScore = 0 - максимальное кол-во очков участника, BestStudentNumber = 0 - номер лучшего участника и BestSchool = 0 - номер лучшей школы по кол-ву баллов.
Программа начинает выполнение цикла for со значением i = 1 до значения меньшего или равного 3 с шагом 1. Этот цикл проверяет все школы.
Следует вложенный цикл for со значением j = 1 до значения меньшего или равного students с шагом 1. Этот цикл проверяет всех участников школ.
В этом цикле инициализируется score = i*10+j*3. Это выражение для кол-ва баллов отдельного участника.
Далее проверка: i == 1 (школа под номером 1?).
Если да, то score1 += score (то есть, школе 1 достаются баллы участника 1 школы).
Иначе проверка: i == 2 (школа под номером 2?).
Если да, то score2 += score (то есть, школе 2 достаются баллы участника 2 школы).
Иначе мы делаем действие: score3 += score (школе 3 достаются баллы участника 3 школы).
Потом консоль выводит сообщение: $"Школа {i}, участник {j}: {score} баллов. Это сообщение показывает, сколько баллов у участников каждой школы.
Следует проверка: score > MaxStudentScore (этот счёт больше максимального?).
Если да, то максимальный счёт перенимает значение этого счёта, записывается номер студента в зависимости от j и номер лучшей школы в зависимости от i.
В итоге, консоль выводит таблицу:
Школа 1: кол-во баллов.
Школа 2: кол-во баллов.
Школа 3: кол-во баллов.
Лучшая школа: номер школы.
Лучший участник: Школа: номер, участник: номер (кол-во баллов).

В это приложении также реализована проверка исключении с помощью try/catch. Есть на проверку 3 исключения: FormatException - Входная строка имела неправильный формат,
OverFlowException - Значение было недопустимо малым или недопустимо большим для Int32, Exception - все ошибки в целом. В каждой проверке исключений происходит изменение цвета на красный,
а также показ сообщения: "Что-то пошло не так! Ошибка: (текст ошибки)".

В конце программа ждёт нажатия клавиши пользователем, предотвращая закрытие сразу после работы.
